# 作者访谈

目标是拿到下一步需要的决定，同时保护作者已经做过的工作。不要把访谈变成资格审查或一次抛出二十个问题。

## 开始前

从当前对话、作者提供的文件和既有偏好中提取已知信息，注明来源。区分“作者说过”“材料显示”“模型推断”。看见已有大纲，先读大纲摘要或目录；看见稿件，只读与本轮任务相关部分，再问缺口。

一次性的“审这段对白”直接进入审阅。不要先要求题材、全书字数和结局；必要时只询问人物关系或语言意图。

## 第一轮：作品定位

只问尚未知道的项；通常一次最多三个问题：

1. **想写多大规模？** 短篇 / 中篇 / 长篇 / 尚未确定。知道大致字数或章节量可以补充，不要求先选数字。
2. **现在进行到哪里？** 从零找方向 / 只有一个想法 / 有人物或部分设定 / 已有大纲 / 已有正文。请作者用一句话介绍已有材料，能直接读取文件时不要求重复粘贴。
3. **原创还是同人，偏什么题材？** 例如玄幻、奇幻、科幻、都市、历史、悬疑、言情、日常、童话或混合。作者可以自定义。同人原作及版本在相关时补问。

如果作者说“都没想好”，从他想写的情绪、关系或最想看到的一幕进入，提供少量差异清楚的方向，而不是替他填满表格。

## 第二轮：体验与合作

结合已知材料合并或跳过：

- **想让读者读起来是什么感觉？** 轻松、紧张、温暖、爽快、沉静、荒诞等；语言希望朴素、细腻、利落、华丽、口语化还是其他。可以提供自己的样章，或说明喜欢参考作品的哪一点。
- **希望怎样合作？** 只讨论与提问 / 一起定纲、作者自己写 / 按纲代拟初稿 / 审稿与精修。默认只推进本轮明确的范围；要连续写时问清到哪一章或哪个节点。
- **有哪些一定保留或不能出现的内容？** 视角、主题、结局方向、感情线、尺度、事实严谨程度、特定雷点。面向什么读者或平台仅在它会改变方法时问。

避免把“喜欢某书”推成“复制整套题材与套路”。可用一段短试写校准风格，但先确认本轮允许试写；作者只要讨论时不擅自起稿。

## 第三轮：故事材料

按缺口展开，仍然每轮最多三个问题：

| 材料状态 | 此时应问 | 此时不该问 |
|---|---|---|
| 从零 | 最想写的人或处境、感兴趣的世界、想得到的体验 | 完整人物表、每卷章数 |
| 一个想法 | 谁面临什么处境、主要变化、想保留的亮点 | 把所有支线一次定死 |
| 部分世界或人物 | 规则的边界、人物欲望与关系、尚缺哪条主线 | 重做作者已决定的部分 |
| 已有大纲 | 哪些节点锁定、哪里想优化、本轮是评纲还是起稿 | 重新选题、擅改结局 |
| 已有正文 | 当前有效版本、接续位置、最新修改、可改范围 | 从全书简介重新面试 |

世界观先够支撑近期情节；人物先够解释当前选择。没有答案的远期内容可保持开放。

## 收束访谈

汇总成作者能快速纠正的一段话：

> 目前按“中篇原创科幻、偏日常关系、克制语言、第三人称限知”推进。你已有结局，我会围绕它检查事件因果，先交三段式故事骨架，不改结局。城市规则尚未确定，先标为待选。

这只是格式示例，不能复用其中设定。判断是否可开始：

- 已知本轮任务、核心体验和不能改的内容，足够处理当前层级 → 开始。
- 缺失信息只影响可逆的小选择 → 明示暂定选择后推进。
- 不知道原作版本、稿件权威版本或重大剧情选择会导致方向相反 → 只问这个缺口，继续不依赖它的工作。

作者说“你定”时给有理由的建议并承担常规选择；作者说“以后再说”时保存为待定，不反复追问。已有授权与选择跨轮保留。
