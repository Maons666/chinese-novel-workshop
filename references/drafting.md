# 正文协作

## 写前准备

根据 [连续性与交付](continuity.md) 读取当前任务需要的材料：作者偏好、有效约束、相关大纲、上一段或上一章的实际结尾、出场人物状态、与本章有关的早期原文。缺少与当前选择有关的关键材料时说明缺口，不以模型记忆填补。

确定本轮是试写、初稿、续写、轻改、精修还是结构重写。现有作者稿始终从最新文件起步；授权“润色”不自动包含改结局、换视角或增加大设定。

## 从材料进入正文

| 作者给什么 | 实际执行 | 应交付什么 |
|---|---|---|
| 已确认的构思与写作意向 | 在本轮授权内补最小场景骨架，立即起草 | 完整短篇或约定范围的正文 |
| 一章大纲 | 展开动作、对话、感知、必要心理与转场 | 有过程和阅读节奏的章节，不是大纲改写 |
| 前文与接续要求 | 核对结尾与相关事实，推进下一场 | 与前文自然衔接的新正文 |
| 原稿与修改要求 | 按轻改、精修或重写范围处理 | 修订后的实际文本；要求时另附改动说明 |
| 连续写作批次 | 逐章写、审、记录本批状态，再推进下一章 | 本轮约定的各章正文及草稿状态 |

信息足够时不以继续访谈代替写作。作者已将小选择交给 agent 时可以合理补足执行细节，但不得新增会改变主线的大设定。完整短篇应有收束；章节的开放结尾也应完成本章承诺，不能在关键过程半途截断。

## 起草

- 因果落在人物能观察到的信息和可以做出的选择上。叙述者、读者和人物掌握的信息分开。
- 重要变化需要可感知的过程；不要把所有情节写成“发生了什么”的摘要。已经熟悉的流程可以简写。
- 情绪可通过叙述、心理、对白、动作和环境共同表达，按视角与文风选择。无需把每个心理句强行改成身体动作。
- 描写有观察顺序和空间关系。细节影响感受、行动、理解或审美体验即可，不要求每件物品承担伏笔。
- 对白考虑人物目的、关系、知识与当下处境；信息交流不等于双方替读者讲解背景。避免每句台词都配无意义动作。
- 节奏来自重点、信息、情绪和场景长短的安排，不由短句数量或固定反转间隔决定。
- 本章完成应完成的过程再结束。章末可以是新问题、选择、局面变化、情绪余波或暂时安定，服从作者的阅读体验目标。
- 成果能够保留和积累；有代价不等于所有成功都立即被撤销。人物的失败也必须符合事件因果。

新增加的临时细节不能与硬约束冲突，也不能未经决定变成影响后续主线的大设定。需要保留的细节在交付时进入草稿状态记录。

遇到大纲扩写感、对白僵硬、属性堆叠或刻意碎句时，读取 [中文正文的具体处理](chinese-prose.md)，根据当前场景选择表达，而不是套用例句。

## 文风校准

依据作者描述与自己的样章，参考 [文风与定制](customization.md)。对语气、叙述距离和密度分别校准。保留作者有作用的重复、口语、长句、短句和留白；不为了“像人写”统一切碎或故意添错。

陌生题材或需要确认的风格，可以先写作者同意范围内的小样；选定后再扩展。既有风格已经明确时不用每章再次试写。

## 改稿力度

| 模式 | 可做 | 不能默认做 |
|---|---|---|
| 只评 | 定位问题、说明影响与修法；作者要求时给局部示例 | 修改正文、更新已发生事实 |
| 轻改 | 明确语病、指代、重复、句间衔接；保留场景与信息 | 重排剧情、改人物立场 |
| 精修 | 在既定事件内调整段落、节奏、对白和必要过程 | 新增主线转折、擅改结局与规则 |
| 结构重写 | 按已授权方案重组场景与事件 | 扩大到未授权章节、悄悄改历史 |
| 续写 | 承接有效结尾、状态和本轮计划 | 将候选稿当作定稿、忽略作者新改动 |

“更有张力”“更有文学性”先翻译成能作用于这篇稿子的具体目标；如果两种理解会导致明显不同的改动，简短澄清。

## 写后处理

按 [审查与审阅](review.md) 做与本轮相称的检查。短段可以合并检查，长章分结构、连续性、语言与阅读体验看，不因固定轮数反复重写已经成立的句子。

能在授权范围内修复的明确问题直接修；涉及作者决定的地方提出有证据的选项。交付文字标明试写或初稿状态，不用模型自评“通过”替代作者接受。

作者指定字数时优先满足情节与约束，再检查统计结果。软目标有偏差时解释，不灌水；硬上限确实无法同时满足时给压缩方案或说明冲突，不截断句子。字数口径在 [连续性与交付](continuity.md) 说明。
