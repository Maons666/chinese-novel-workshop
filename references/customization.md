# 文风与定制

定制分两层：**单本书的偏好**存作品工程；**通用技能的方法改进**才改技能仓库。不要因一个作者本次喜欢短句，就把所有作品改成短句。

## 偏好档案

使用 [作者偏好模板](../templates/author-profile.md) 或已有等价文件。每项记录值、状态、来源和作用范围：

- 已确认：作者明确表达。
- 暂定：为推进当前可逆工作选择，作者可随时更改。
- 待定：目前不作决定。

类型混合、篇幅开放、没有感情线、无固定大纲都允许。自然语言描述可以比枚举值更准确。作者不需要理解配置文件才能使用技能；由 agent 把对话整理成可读档案。

## 文风从证据中提炼

优先作者自己的样章或已明确认可的文本。先判断样本是当前目标风格、旧稿问题样本还是仅参考某一点，再提炼：

- 视角与叙述距离。
- 句段节奏、信息密度、叙述与对话关系。
- 描写的观察顺序和细节选择。
- 心理、情绪、幽默及留白的呈现方式。
- 人物声音与叙述声音的区别。

描述“何时这样写、产生什么效果”，不要只统计形容词和句长。样本少时说明局限；不能把样本中的人名、世界事实、情节和价值判断迁入新书。

必要时写同一小场景的不同处理供比较，只有作者确实需要选风格时才这么做；不强制每章多稿。

## 作者修改后的学习

对照准确的修改前版本与作者最新文本，区分：

1. 明确更改了事实或情节。
2. 只在当前场景成立的措辞调整。
3. 多处反复体现、可能可推广的笔法偏好。
4. 原因不明，暂不推断。

作者明确说“以后都按这个方向”时记录通用偏好；单个改句不自动升级成禁令。提炼到具体效果，例如“交代清楚回指对象”，而不是“以后不能出现某个词”。

## 改偏好与改设定

作者说“后面节奏快一点”，默认作用于后续写作，不自动重写历史章节。记录起效范围、受影响方法和审阅重点。

作者说“把全书改第一人称”，这会改变现有稿件和信息边界。先说明受影响范围，按照已有授权决定执行还是只交方案；不能悄悄做半套修改。

合作方式同样可切换：从代拟改为只做教练时，停止正文代写；从只评改为按意见修订时，按新增授权执行，保留有效的前序决定。

## 扩展方法

需要新题材时，优先在方法路由中增加一个条件和专项参考，不复制完整主流程。每个新方法写明适用情形、判断标准与不适用边界，并增加真实场景验证。

方法之间冲突时，先按作者目标和硬约束裁决；仍有实质分歧，给出具体后果供作者选择，不让多个模块互相覆盖。
