# 方法选择

把作者意向转成可解释、可调整的工作方法。不要给作者显示内部术语评分表；用“为什么适合这本书”解释取舍。

## 四步选择

1. 按**当前材料与任务**选择入口。
2. 按**篇幅与连载方式**决定规划、记忆粒度。
3. 按**主要阅读体验与题材**选择专项方法；主体验优先，题材辅助。
4. 用**硬约束、文风、合作方式**修正方案，并写回偏好档案的方法栏。

仅记录本轮确实采用的方法。示例：

> 已有中篇悬疑大纲，本轮只评纲：采用双时间线与线索可见性检查，补人物选择的因果；不重做题材定位，不增加新凶手。交付问题清单与局部方案。

## 材料入口

| 作者状态 | 适合的方法 | 本轮典型产物 |
|---|---|---|
| 从零 | 从体验或人物困境探索少量不同方向，比较可写性 | 方向候选及取舍 |
| 一个想法 | 提炼人物、处境、变化和可持续事件来源 | 核心构思与短骨架 |
| 人物或世界先行 | 从人物目标与世界限制寻找具体事件 | 关系图、规则边界、近期事件 |
| 完整大纲 | 检查因果、节奏、人物选择和兑现；锁住已定节点 | 评纲或当前章场景安排 |
| 已有正文 | 从实际正文恢复事实和文风，核对接续位置 | 接续任务单或范围内审稿 |
| 想边写边找 | 只规划近期目标与不可变条件，试写后逆向整理 | 探索性草稿与已发生事实 |

“大纲法”和“探索式写作”不是互斥身份。允许某卷定纲、局部探索；试写产生的新方向在作者接受前保持候选。

## 篇幅与记忆

| 规模 | 规划重心 | 最小记忆 |
|---|---|---|
| 短篇 | 一个主要变化，选择与结尾相互支持；支线服务核心 | 一页创作简报，必要的人物与事实 |
| 中篇 | 少数阶段目标、主要人物关系的递进、支线收束 | 简报、阶段大纲、人物状态、关键线索 |
| 长篇 / 连载 | 全书方向 → 分卷目标 → 近期章纲；成长与关系能积累 | 按需加载的规则、人物、时间线、伏笔和章节索引 |

分类不绑定统一字数门槛。作者指定长度时记录单位、统计范围和软硬程度；“约三千字”是目标，不是自动补齐命令。总量不清时按情节复杂度讨论可行规模。连载需要持续阅读动力，但动力也可以来自关系发展、稳定回报或生活变化。

## 按阅读体验与题材选择专项方法

| 方向 | 应关注的写法与审查 | 不自动附加 |
|---|---|---|
| 日常 / 治愈 / 关系 | 日常目标、相处差异、习惯与关系的细微变化、余韵 | 每章危机、强反转、配角工具化 |
| 成长 / 冒险 / 爽感 | 可理解的目标、投入与回报、能力边界、阶段成果与后续机会 | 每次成功都撤回成果、必须吃瘪、固定打脸循环 |
| 悬疑 / 推理 | 发生顺序与披露顺序分开；线索可见性、误导公平、解释成本 | 全知角色、隐去解谜必需的信息、为反转临时换真相 |
| 言情 / 人物关系 | 各自目标、吸引与阻碍、边界、关系变化的触发与后果 | 固定性别角色、强行误会、必须感情线 |
| 玄幻 / 奇幻 | 力量或奇异规则的边界、资源、文化、成长后果 | 等级面板、系统金手指、强制升级路线 |
| 科幻 | 假设与现实知识分开；技术限制及二阶社会后果 | 用术语替代因果、把假设写成已证实科学 |
| 都市 / 历史 / 职业 | 生活流程、身份与制度、时代或职业细节、可信的行动条件 | 将常识推测当专业事实、让所有专业人士失能 |
| 同人 | 原作版本、人物认知与声口、保留的正典、明确的改动 | 自动接受其他改编版本、把二设当官方 |
| 幽默 / 荒诞 / 寓言 | 叙述立场、预期落差、内部规则与语气一致 | 强行写实化、逐句解释笑点 |
| 混合题材 | 先问主要体验，再选能支撑它的两三项方法 | 把所有类型规则同时启用 |

风格与题材分开：玄幻可以朴素日常，都市可以奇诡，短篇也可以慢节奏。根据作者目标评价，不按通用畅销模板扣分。

## 合作与审阅强度

- **教练**：用问题、诊断和选项帮助作者，不代写正文。
- **共创**：提供方案或局部示例，作者决定关键方向。
- **代拟**：按已经明确的任务与约束起草，自查后交作者。
- **编辑**：按只评、轻改、精修、结构重写分别控制修改量。
- **连续推进**：在明确批次内逐章执行，沿用暂定草稿链，不擅自宣布定稿。

审阅的公共底线是约束、因果、人物信息与表达可理解性。专项重心随作品变化：悬疑多查线索，日常多看关系与余味，科幻多查假设和后果。可以调整审阅顺序和深度，不把个人审美标成硬错误。
