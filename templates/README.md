# 模板怎么用

模板是供 agent 裁剪的输出资产，不是要求作者逐格填完的问卷。空白项可以删除，未知项标“待定”；只有有用的字段才保留。

| 模板 | 何时用 |
|---|---|
| [作者偏好档案](author-profile.md) | 多轮合作需要记住意向与文件映射时 |
| [故事简报](story-brief.md) | 新构思需要一个共同依据时 |
| [章节任务单](chapter-brief.md) | 起草或续写前需要锁定当前范围时 |
| [故事状态](story-state.md) | 跨场景、跨章事实开始难以靠简报维护时 |
| [审阅报告](review-report.md) | 需要交付审查与读者反馈时 |

新短篇通常只需要一份简报和正文；偏好与状态可作为简报中的小节。中长篇再按需要拆文件，例如作者偏好、设定、大纲、人物、正文、连续性与审阅。

作者已有文件时，把职责映射过去，不创建重复文件。作者没有指定存储目录时，先在对话完成可行部分；需要持久化时确认保存位置或沿用明确的项目根目录。技能仓库保存可复用方法，作品项目保存私人书稿，两者分开。
